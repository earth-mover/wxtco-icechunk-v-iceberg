## Learned

See `docs/findings/notes.md` (2026-09-18 session 003): obstore 0.11.1 rejects `region=None`,
raises builtin `FileNotFoundError` (its `NotFoundError` is deprecated), `LocalStore` lists
empty directories as prefixes. The copy bucket root carries `_code/`, `_logs/`, `_progress/`,
so `available_cycles` skips non-digit prefixes.

Review fixes worth knowing about: `Settings.from_env` loads `.env` from the CWD explicitly;
`verify_copy` byte count covers only wanted surface keys; fixture time coords share one epoch
(`seconds since 1970-01-01`); `copy verify` exits 1 when the source cycle is absent.
